Este repositório contém as entregas do projeto de Sistema de Dimensionamento Energético Residencial, divididas por Sprints (Checkpoints).

## 📂 Organização do Repositório

- 🚀 **[Sprint 1](./sprint1/)**: Primeira fase do projeto. Contém o MVP do sistema, englobando o cadastro de imóveis, registro de faturas de energia, cálculo do mês de pico, consumo máximo e média de consumo. A documentação completa de arquitetura, stack (React + Node.js/SQLite) e como rodar a Sprint 1 está dentro da pasta.
- ☀️ **[Sprint 2](./sprint2/)**: Segunda fase do projeto (CP2). Incorpora o módulo de dimensionamento fotovoltaico residencial, seleção técnica de equipamentos a partir de datasets reais (módulos, inversores, baterias), verificação de compatibilidade técnica e orçamento com segregação de custos. Inclui documentação e relatório de evidências de cálculo.
